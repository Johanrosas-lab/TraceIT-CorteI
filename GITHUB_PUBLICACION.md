# Publicación del repositorio en GitHub

Repositorio previsto: `https://github.com/johanr-lab/TraceIT-CorteI`

Antes de entregar al docente, crea un repositorio público llamado `TraceIT-CorteI` en tu cuenta `johanr-lab` y ejecuta desde esta carpeta:

```bash
git remote add origin https://github.com/johanr-lab/TraceIT-CorteI.git
git branch -M main
git push -u origin main
```

Verifica después que el enlace abra sin iniciar sesión y que el historial de commits aparezca correctamente.
