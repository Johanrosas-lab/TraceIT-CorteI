# Checklist antes de entregar

1. Completar en la bitácora los campos `Curso`, `Docente` y `Fecha de entrega` cuando el profesor los confirme.
2. Firmar la declaración de honestidad de la bitácora.
3. En el Mac, crear el entorno virtual, instalar `requirements.txt` y ejecutar el CRUD.
4. Ejecutar `pytest -q` y confirmar que las pruebas pasan.
5. Crear en GitHub el repositorio público `johanr-lab/TraceIT-CorteI`.
6. Publicar el historial local de Git con los comandos incluidos en `GITHUB_PUBLICACION.md`.
7. Abrir el enlace del repositorio sin sesión iniciada y verificar README, código y commits.
8. Sustituir en el PDF del proyecto cualquier nota de “publicar antes de la entrega” por el enlace definitivo si se desea una versión completamente final.
9. Entregar los tres archivos solicitados: proyecto, bitácora y prototipo.
